# 전문 기자재 쇼핑몰 상담원을 위한 근거 기반 문의 분석·답변 작성 지원 시스템

**2026학년도 2학기 충남대학교 종합설계2 | 5조(Labigator)**  
**창의SW/AI축전 출품명:** 전문 기자재 쇼핑몰의 운영 효율 극대화를 위한 AI 기반 문의 처리 자동화 에이전트

## 1. 프로젝트 소개

전문 기자재 쇼핑몰에서는 고객이 상품의 규격, 수량, 호환성, 재고, 납기 등을 한 번에 문의하는 경우가 많습니다. 상담원은 문의 내용을 파악하고 관련 상품 자료를 비교하며, 정보가 부족할 경우 고객에게 추가로 질문해야 합니다.

본 프로젝트는 이러한 업무를 지원하기 위해 **고객 문의의 핵심정보를 구조화하고, 누락·모호한 정보를 구분하며, 상품 및 근거 자료를 확인할 수 있도록 돕는 상담원 보조 시스템**을 목표로 합니다.

AI가 모든 답변을 자동 확정하거나 고객에게 단독 전송하는 방식이 아니라, **상담원이 결과를 검토하고 최종 판단하는 방식**을 지향합니다.

## 2. 주요 기능 및 개발 범위

| 구분 | 기능 | 진행 구분 (2026.11.18 기준) |
| --- | --- | --- |
| US-01 | 고객 문의 접수·조회 | Sprint 1 대상, 데모 구현·검증 기록 확인 필요 |
| US-02 | 문의 의도·핵심정보 구조화 | Sprint 1 대상, 데모 구현·검증 기록 확인 필요 |
| US-03 | 누락·모호한 필수정보 식별 | Sprint 1 대상, 데모 구현·검증 기록 확인 필요 |
| US-04 | 추가 확인 질문 문안 제안·수정 | Sprint 2 기본 계획 |

| US-06 | 규격서·매뉴얼 등 출처 확인 | 후속 개발 후보, US-05 검증 완료 시 Sprint 2 대안 검토 |

## 3. 서비스 이용 흐름

1. 상담원이 고객 문의 원문을 선택합니다.
2. 시스템이 문의 의도·상품명·규격·수량 등의 정보를 정리합니다.
3. 누락되거나 모호한 항목을 확인 필요로 표시합니다.
4. 상담원은 추가 질문 문안과 관련 상품 후보를 검토합니다.
5. 관련 자료·출처를 확인한 뒤 답변 초안을 검토·수정합니다.
6. 최종 발송 여부는 상담원이 결정합니다.

※ 4~6단계에는 현재 개발 계획에 포함된 기능이 있으며, 전체 흐름이 모두 구현 완료된 상태를 의미하지 않습니다.

## 4. 개발 환경

Sprint 1 계획 문서에 기재된 개발 기준은 다음과 같습니다.

- Java 17 / Spring Boot 3.5.16
- H2 2.3.232
- Gradle
- HTML / CSS / JavaScript 기반 웹 화면
- 외부 LLM 연동을 분리한 `LlmAdapter` 구조

실제 최신 데모의 버전·설정은 소스코드 및 실행 검증 후 이 항목에 반영할 예정입니다.

## 6. 저장소 및 실행 안내

현재 이 저장소의 `main` 브랜치에는 문제정의서, 시스템 설계 문서, Sprint 문서 및 발표자료 등 **프로젝트 산출물**이 우선 정리되어 있습니다.

Sprint 1 데모의 소스코드·실행 파일·실행 명령은 별도 자료를 검증하여 저장소에 반영할 예정입니다. **현재 저장소만 내려받아 바로 실행할 수 있다고 안내하지 않습니다.** 실행 방법은 소스코드 업로드 후 추가하겠습니다.

## 7. 검증 및 유의 사항

- 누락·모호한 규격 또는 수량은 임의로 확정하지 않습니다.
- 가격·재고·납기·호환 정보는 근거 없이 확정하지 않습니다.
- 자료가 없거나 외부 AI 호출이 실패한 경우, 확인 필요 상태를 구분하도록 설계합니다.
- 답변 초안 생성만으로 승인 완료 상태가 되지 않도록 합니다.
- 고객에게 AI 답변을 자동 발송하지 않는 것을 기본 원칙으로 합니다.
